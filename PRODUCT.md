# Product

## Register

product

## Users

One operator using the Windows desktop app to submit project-scoped work and monitor a team of Feishu-connected agents.

## Product Purpose

Provide a local workspace for planning, running, observing, pausing, resuming, and stopping multi-agent tasks while keeping project history and context isolated.

## Brand Personality

Clear, calm, controllable. The interface should make current task state and available actions easy to understand without exposing hidden model reasoning.

## Anti-references

- Dense dark dashboards that give equal weight to settings, task entry, task lists, and event logs.
- Interfaces that expose private chain-of-thought as an execution trace.

## Design Principles

- Keep conversation and task input as the primary workspace.
- Make project and history navigation persistent and compact.
- Put execution detail one step away, available per agent or task.
- Preserve explicit project isolation and lifecycle controls.
- Show structured progress and actionable connection errors, never hidden reasoning.

## Accessibility & Inclusion

Use readable contrast, visible keyboard focus, semantic controls, and respect reduced-motion preferences.
