# Agent CLI 实现计划

> **For agentic workers:** 按步骤执行，每完成一个阶段都运行对应测试。

**目标：** 为 Agent 提供受控的确定性 CLI，减少重复推理和冗长日志，同时保留现有网关、编排器和项目隔离边界。

**架构：** 新增 `src/agent-cli.js` 作为纯业务适配层，负责测试摘要、任务状态、交付校验和图表渲染；新增 `scripts/agent-cli.mjs` 作为参数解析和 JSON 输出入口。CLI 不直接改变任务状态，不替代飞书消息、审批和 Agent 派发。

**技术栈：** Node.js ESM、现有 `TaskStore`、`task-status`、交付校验和图表模块，Node 内置 `child_process` 用于受控测试命令。
